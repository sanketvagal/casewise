# Configure custom visit types and durations

Administrators and scheduling coordinators can create tailored visit categories to streamline patient intake.

1. Navigate to **Settings > Scheduling > Appointment Types**.
2. Click **New Type** in the top right corner.
3. Enter the display name, default duration in minutes, and select a calendar color code.
4. Check the box for **Require Intake Form** if patients must complete pre-visit paperwork.
5. Click **Save**.

### Limits and Conditions
Custom types require a minimum duration of 5 minutes and a maximum of 480 minutes. Deactivating a type preserves historical calendar data but removes it from future booking options.

### Troubleshooting
If a newly created visit type does not appear on the patient booking screen, check **Settings > Scheduling > Locations** to ensure the type is enabled for that specific facility. If issues persist, verify that your user role includes the `Manage Appointment Types` permission under **Settings > Staff > Roles**.
