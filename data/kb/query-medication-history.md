# Query external medication history and prescription monitoring

Clinicians can retrieve a patient's multi-pharmacy fill history and state prescription monitoring program (PMP) data directly from the clinical workspace. Users must have active prescribing credentials and completed identity proofing.

1. Open the patient chart and navigate to **Clinical > Medications**.
2. Click **Query External History** in the toolbar.
3. Review the identity verification prompt and select **Authorize & Submit**.
4. View the consolidated report detailing prior fills and controlled substance data.

### Limits and Conditions
Queries depend on state database availability and patient consent where required by local regulations. Historical data is restricted to the preceding twelve months.

### Troubleshooting
If the query fails or returns an access error, verify that the clinician's National Provider Identifier (NPI) and Drug Enforcement Administration (DEA) numbers are correctly entered under **Settings > Provider Profile**. If the state PMP gateway is offline, a notification banner will appear; wait fifteen minutes before retrying.
