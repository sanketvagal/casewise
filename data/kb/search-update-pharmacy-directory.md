# Search the pharmacy directory and update patient favorites

To update a patient's preferred pharmacy or add a custom entry, navigate to **Patients > Chart > Demographics** and select the **Pharmacy** tab. 

1. Click **Search Directory** to query the national e-prescribing database using the pharmacy name, NPI, or zip code.
2. Select the correct facility from the results list and click **Set as Preferred** to update the patient's record.
3. If a newly opened location is missing from the database, click **Add Custom Pharmacy**, complete the required fields (Name, Address, Phone, and Fax), and click **Save Entry**.

**Limits & Conditions:** 
Custom pharmacies are restricted to your clinic's database and cannot receive electronic prescriptions until verified by network administrators. Only staff with Medical Assistant or Provider roles can modify pharmacy favorites.

**Troubleshooting:** 
If a pharmacy search yields no results, verify the zip code or try searching by phone number alone. If an added custom pharmacy fails to appear in the drop-down menu when prescribing, refresh your browser cache using `Ctrl+F5` (`Cmd+Shift+R` on Mac) and ensure all mandatory address fields were completed.
